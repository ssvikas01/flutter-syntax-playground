# Learning Roadmap

## Stage 1 — Dart essentials
- [ ] Variables and types
- [ ] Operators and expressions
- [ ] Conditions, loops, and switch
- [ ] Functions and optional parameters
- [ ] Lists, sets, maps, and collection operations
- [ ] Null safety and null-aware operators
- [ ] Classes, constructors, and methods
- [ ] Futures, async, and await

**Practice:** write a command-line expense tracker using a list of objects.

## Stage 2 — Flutter UI
- [ ] Understand `main()`, `runApp()`, and the widget tree
- [ ] Use `MaterialApp`, `Scaffold`, `AppBar`, `Text`, and `Icon`
- [ ] Arrange widgets with `Row`, `Column`, `Padding`, and `Expanded`
- [ ] Build reusable widgets
- [ ] Handle taps and update state with `setState`

**Practice:** make a counter app with increment, decrement, and reset.

## Stage 3 — Navigation and forms
- [ ] Navigate between screens
- [ ] Read text input with a `TextEditingController`
- [ ] Validate a `Form`
- [ ] Display submitted data

**Practice:** create a profile form with name and course fields.

## Stage 4 — Good habits
- [ ] Format with `dart format .`
- [ ] Analyze with `flutter analyze`
- [ ] Give widgets and variables clear names
- [ ] Extract repeated UI into methods or widgets
- [ ] Read analyzer messages instead of ignoring them

## Completion test
Build a simple task list that lets you add tasks, mark them complete, and navigate to a detail screen. Explain how each widget and state variable works.
